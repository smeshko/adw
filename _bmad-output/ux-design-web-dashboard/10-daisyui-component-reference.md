# 10. DaisyUI Component Reference

Quick reference for the DaisyUI components used across the dashboard.

| Component | DaisyUI Class | Used For |
|-----------|--------------|----------|
| Stats row | `stats stats-horizontal shadow` | Overview + analytics stat cards |
| Individual stat | `stat` with `stat-title`, `stat-value`, `stat-desc` | Each metric card |
| Card | `card card-compact card-bordered` | Active run cards, project cards, section wrappers |
| Table | `table table-sm table-zebra hover` | Recent runs, runs list, analytics breakdown |
| Badge | `badge badge-sm badge-{success\|error\|warning\|ghost}` | Run status indicators |
| Collapse/Accordion | `collapse collapse-arrow bg-base-200` | Phase detail sections |
| Tabs | `tabs tabs-boxed` | Analytics time range, optionally header nav |
| Select | `select select-bordered select-sm` | Filters, project selector |
| Input | `input input-bordered input-sm` | Search, date filters |
| Textarea | `textarea textarea-bordered` | Feature description |
| Button | `btn btn-{primary\|error\|ghost} btn-{sm\|md}` | Actions |
| Modal | `modal` + `modal-box` | New run, abort confirmation |
| Steps | `steps steps-horizontal` | Phase pipeline visualization |
| Progress | `progress progress-{primary\|warning\|error}` | Budget usage bar |
| Swap | `swap swap-rotate` | Theme toggle |
| Join | `join` with `btn btn-sm` | Pagination |
| Alert | `alert alert-error` | Failed run banner |
| Loading | `loading loading-spinner\|loading-dots` | Loading states |
| Mockup Code | `mockup-code` | Log viewer (optional) |
