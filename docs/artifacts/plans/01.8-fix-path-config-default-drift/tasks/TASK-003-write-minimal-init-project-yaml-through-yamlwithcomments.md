# TASK-003: Write minimal-init project.yaml through YAMLWithComments

Depends on: None
Suggested commit: `fix(init): write minimal project.yaml through the shared generator`

## Goal

`adw init --no-interactive` writes a `project.yaml` that loads and passes `adw validate` (B11). Minimal init and the wizard share one generator each for `project.yaml`, `.gitignore` and `.env.template`, and both write `name` as the directory name.

## Files

- `src/adw/config/initializer.py`:
  - Delete the three class attributes `DEFAULT_CONFIG_TEMPLATE`, `GITIGNORE_CONTENT` and `ENV_TEMPLATE_CONTENT`.
  - Add module-level `generate_gitignore() -> str`, using the wizard's content (`runs/`, `logs/`, `*.log`, `state.json`, `.env`), and `generate_env_template() -> str`, using the existing content.
  - `_write_config(config)` builds a `WizardState`, calls `state.update_config("basics", {"project_name": self.project_root.name, **config})`, and writes `YAMLWithComments(ConfigRegistry()).generate_project_yaml(state)`.
  - `_write_gitignore` and `_write_env_template` call the new functions.
- `src/adw/cli/wizard/summary.py`: delete its own `generate_gitignore`/`generate_env_template` and import them from `adw.config.initializer`. The `cli/wizard/__init__.py` re-export keeps working through the import.
- `src/adw/config/yaml_generator.py`: the header line becomes `# Generated by adw init on {date}`.
- `src/adw/cli/wizard/basics.py:run_basics_step`: the returned dict adds `"project_name": root.name`. Update the docstring's "containing" list.
- The header assertions in `tests/unit/config/test_yaml_generator.py:62,193` and `tests/unit/cli/wizard/test_summary.py:476`: assert the new text. The phase-config header at `yaml_generator.py:420` is wizard-only and stays.
- `tests/unit/config/test_initializer.py`: add `test_initialize_writes_loadable_config`.
- `tests/unit/cli/test_init.py`: add `test_init_output_passes_validate`.
- `tests/unit/cli/wizard/test_basics.py`: the `run_basics_step` tests (~120–168) expect `project_name == Path.cwd().name`. `tests/unit/cli/conftest.py` makes cwd `tmp_path` for `wizard/` too, and `run_basics_step` defaults `project_root` to cwd.
