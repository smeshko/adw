## Architecture Facts

- **Real run layout** (main checkout, 44 runs):
  - `runs/<id>/` holds `context.json`, `live.log`, `live.log.lock`, `artifacts/`, `llm/`, `logs/` (empty) and `snapshots/`.
  - `llm/` holds `001_plan_response.json` … `005_ship_response.json`, named `f"{phase_index:03d}_{phase}_response.json"` (`phase_runner.py:1360`).
  - The phase name is the filename with the leading `NNN_` and the trailing `_response.json` removed.
- **Real `live.log` lines** after ANSI stripping:
  - `[2026-02-13 07:10:29] [LLM] ▶ Token stream begins (plan)`, `[TOOL] …` lines, and `LogEvent` lines of the form `[ts] [INFO] [PHASE] {…} msg`.
  - The dashboard regex `^\[(ts)\]\s+\[(\w+)\]\s+(.*)` matches all three. Token-stream body lines don't match. `_load_log_entries` skips them; `log_stream_sse` emits them as INFO.
- **Token counts agree across sources.** `context.json` `phase_tokens` equals input + output from the matching response file, e.g. plan: 25403 + 11641 = 37044.
- **`ProjectConfig` requires `name`.** `generate_project_yaml` with basics `{project_name, language, test_command, build_command: None}` loads through `ConfigLoader`, and `adw validate` reports 0 errors and 0 warnings (prototyped in a scratch repo).
- **`TaskManagerConfig()` already has `ship: Done`.** Only the wizard's explicit-mapping path and `sync.py`'s empty-mapping fallback lose it.
- **The index entry for real run `01KHAPGM6PRX55TZQF5V082DDH`** in `~/.adw/index.jsonl` has `project_path` equal to the main checkout, so a dashboard started from the worktree shows it.
- **`asyncio_mode = "auto"`** (`pyproject.toml`): async tests need no marker.

## Constraints

- Tests follow ADR-001: no tests of constant values. The tests below assert trivia and are deleted rather than updated:
  - `TestPhaseStatusMapping`'s five `test_default_mapping_*` tests in `tests/unit/task_managers/test_sync.py`
  - `TestConstants::test_default_state_mappings_covers_all_phases`
- CLI and dashboard unit tests already run in their own `tmp_path` cwd (`tests/unit/cli/conftest.py`, `tests/unit/dashboard/conftest.py`). `HOME` is isolated per test.
- No pytest `--timeout` plugin. Tests that could hang on today's code use `asyncio.wait_for`.
- mypy `--strict`: new functions need full annotations, and the `default_factory` lambda must return `dict[str, str]`.

## Uncertainty

- **Does `interrupted` belong with the failures on the events stream?** Resolved: yes. The client distinguishes only `run-complete` from `run-failed`, and an interrupted run did not complete.
- **Should per-phase cost stay?** Resolved with the user: keep it, priced from the per-phase response files.
- **Which `.gitignore` content wins?** Resolved: the wizard's superset. Minimal init gains `logs/` and `state.json` lines, which do no harm.
- **Will `ProjectInitializer`'s callers break when it returns a config dict built from the same `WizardState` basics?** Resolved: `cli/init.py:_show_init_summary` reads only `language` and `test_command` from the returned dict, and `initialize()` keeps returning it.
